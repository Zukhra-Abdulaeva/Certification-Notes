**Day:** 01
**Topic:** Linux File System
**Status:** `Review`

## Key Learning

* Linux uses a hierarchical file system.
* `/` is the root of the entire file system.
* Important directories such as `/etc`, `/home`, `/var`, and `/usr` have specific purposes.

## Practical Work

**Task**

> Navigate through the Linux file system and identify the purpose of the main directories.

**Commands / Tools**

```bash
pwd
ls
cd /
ls -la
cd /etc
cd /home
```

**Result**

> I navigated through the Linux file system and identified the purpose of several important directories. I also learned how `pwd`, `ls`, and `cd` are used for basic file-system navigation.

## Capability Gain

* Navigate the Linux file system using the command line.
* Identify common Linux directories.
* Use basic shell navigation commands confidently.

## Core Insight

> Understanding the Linux file-system hierarchy is essential for navigating, configuring, and troubleshooting a Linux system.
