📘 Certification Notes
- A centralised knowledge portfolio for my IT certification preparation.
- It is updated daily and is structured, consistent and immediately visible to recruiters.

🎯 Aim of the project: This repository serves as an ongoing learning archive for various IT certifications.
Every day, I add the following to each category:
- new learning points/notes,
- exam-style questions,
- a practical task/lab,
- a diagram (where relevant).

This creates a dynamic portfolio that shows how I think, learn and solve problems – something recruiters love.

Every notes.md file contains:
- 📝 1. Daily Notes: Short, concise learning points on concepts, tools and best practices.
- ❓ 2. Exam Questions: Typical exam questions with answers and explanations.
- 🔧 3. Practical Tasks: Hands-on exercises, labs, CLI commands, cloud set-ups, network configurations, etc.
- 📊 4. Diagrams: Architecture sketches, network diagrams, cloud flows, Kubernetes topologies.
